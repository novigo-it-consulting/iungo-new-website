# Glossário de tradução

Termos que se repetem no site. Use a mesma tradução em todas as páginas.

| Português | English | Español |
| --- | --- | --- |
| Solicitar Demonstração | Request a demo | Solicitar demostración |
| Área do Cliente | Client area | Área de clientes |
| Saiba mais | Learn more | Saber más |
| Ler case completo | Read the full case | Leer el caso completo |
| Ver solução completa | View the full solution | Ver la solución completa |
| Conhecer a Plataforma | Explore the platform | Conocer la plataforma |
| Agendar diagnóstico | Schedule a diagnosis | Agendar un diagnóstico |
| Caso de sucesso | Case study | Caso de éxito |
| Depoimentos | Testimonials | Testimonios |
| Tecnologia comprovada | Proven technology | Tecnología comprobada |

Não traduzir: Iungo, nomes de produto (Organizer, Behavior, Concierge, Resolve, Attendant, Convert, IoT, PIM, CDP), siglas (LGPD, RFID, RTLS), nomes de clientes, e-mails, CNPJ e endereço. Moeda permanece em reais.
